# Ícones da extensão

O `manifest.json` referencia 4 PNGs nesta pasta:
- `icon-16.png`
- `icon-32.png`
- `icon-48.png`
- `icon-128.png`

Para começar, gere quatro PNGs quadrados em qualquer ferramenta (Figma, Photoshop, ou online) e salve aqui. Sugestão visual: fundo verde-menta `oklch(0.80 0.14 165)`, glifo de camadas (3 linhas paralelas) em `oklch(0.16 0.012 250)`.

Sem ícones reais, o Chrome carrega a extensão mas mostra um placeholder cinza.
